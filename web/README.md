# NULL CITY — PBR Web preview

公開先：**https://goroman.github.io/null-city-04/**

現在のBlender組立モデルをGLBへ出力し、`@google/model-viewer` 4.4.0で表示する静的Web UI。回転・ズーム・移動、俯瞰／正面／右側面／背面／上面、分解スライダー、Tab5 チルト（15〜45°）、天板の M3 × 40 mm ねじ、チルト軸、Tab5 抜け止めと PLA 指定の表示、ケース透過、LED点灯、HDR IBL、環境回転・HDR背景、SSAO、任意の自動回転に対応。デカール、金属・粗さ、透過、クリアコート、発光をGLBに保持する。GLBはメートル単位、外幅0.300 m。照明・材質は完成イメージで、実物の配線・光学・温度検証ではない。

ショートカットは Z（俯瞰）、X（正面）、C（右側面）、V（背面）、B（上面）。スペースで組立と分解を切り替えます。分解スライダーを 100% より右に進めると H3C の造形配置に切り替わり、6 枚のプレートに全造形部品を並べます。個別のプレートにも切り替えられます。プレートごとの素材と時間は 3D 位置に追従するラベルに表示します。時間は Bambu Studio の H3C・エンジニアリングプレート・0.4 mm ノズル・積層 0.20 mm・サポートなしでのスライス見積もりです。

## ローカルで確認

Node.js 24以降とnpmを使用する。

```sh
npm ci --prefix web
npm run dev --prefix web
```

表示先は `http://127.0.0.1:4173`。公開用ビルドは `npm run build --prefix web`。依存ライブラリ、フォント、モデル、ポスターは同じ公開先へ配置し、CDNには依存しない。

## モデル更新

形状・材質を変更したら、先に `NULL_CITY_NC04.py` で最新の `.blend` を生成する。その後：

```sh
npm run model:export --prefix web
npm run build --prefix web
```

Blender実行ファイルが標準の場所にない場合は `BLENDER=/path/to/blender npm run model:export --prefix web`。

`public/model/nc04.glb` と `manifest.json` をコミットする。生成スクリプトは元のblendを保存せず、造形部品と外観部品を出力し、床・カメラ・照明器具を含めない。Blenderのmm座標はGLBのルートでメートルへ変換し、各部品の動きを1本の `Assembly` アニメーションにまとめる。乳白カバーは非発光時のベース色を白とし、RGB は発光チャンネルに持たせる。

ビルド時には元モデル・設計入力・GLBのSHA-256を照合する。古いGLBが残っていたらCIを失敗させ、古いプレビューの公開を防ぐ。Actions上でBlenderを再実行せず、検証済みのエクスポートを配信する。

## 検証と自動公開

```sh
npm run build --prefix web
cd web
npx playwright install chromium
npm test
```

macOSでインストール済みChromeを使う場合は `PW_USE_CHROME=1 npm test`。Playwrightは本番ビルドを `/null-city-04/` 配下で開き、PC・スマートフォンでGLB読み込み、寸法・材質、視点、分解、発光、透過、露出（EVと実際の描画輝度）、回転、リセット、横はみ出し、読み込み失敗時の表示を確認する。GLBはKhronos glTF Validatorでも検証する。

## HDR IBL / SSAO

Poly Havenの **Studio Small 03 / Studio Small 02**（Greg Zaal、CC0）を1K Radiance HDRとして `public/environments/` に同梱する。環境選択でIBLを切り替え、環境の回転でモデルを動かさず反射・照明とHDR背景を回す。既定はStudio 03、環境角90°、露出0 EV（内部倍率0.8）、背景非表示。元画像・取得元・ライセンス・SHA-256は同ディレクトリの `manifest.json` と公開先の `project/HDRI_CREDITS.txt` に記録する。

ビルドではハッシュとHDRデコードを検証。両画像とも1024 × 512、RGB値が有限かつ1.0を超える実際のHDRであることを確認する。色調変換前のピーク輝度はStudio 03が3565.93、Studio 02が694.71。トーンマップ済みJPEGを照明へ流用していない。

`@google/model-viewer-effects` の高精度バッファでSSAO→LED限定Selective Bloom→SMAA→Khronos Neutralの順に処理する。SSAOはON／OFF可能。MSAAは無効にして深度効果との不整合を避ける。環境回転は公開されているcustom-pass API経由でThree.jsのSceneへ適用し、モデルの回転角とは独立させる。

自動回転は待ち時間0 ms・20°/秒。スマートフォンでスイッチがモデル表示領域より下にある場合は、ON時にネイティブのフォーカス移動完了後、モデルが見える位置へ即座に戻す。モデル上の回転ボタンからもON／OFFできる。テストではONという属性だけでなく、実際の角度増加とOFF後の停止を確認する。

CIのGPUはSwiftShaderによるソフトウェア描画のため、PC・モバイル検証は入力方法・画面サイズを維持しつつDPRを0.5に設定する。ローカルのiPhoneエミュレーションはDPR 3のまま検証し、公開ページの解像度は変更しない。回転テストは両方で実際の角度増加・停止を必須とする。

## 露出とLEDの自己発光

環境光の強さは0〜2倍で、IBLとHDR背景にのみ作用し、LEDの自己発光へは掛けない。露出は−3〜＋3 EV（0.1 EV刻み）。0 EVが既定の明るさで、描画倍率は `0.8 × 2^EV`。＋1 EVで2倍、−1 EVで半分になり、リセットで0 EVへ戻る。カメラの露出として、反射光・自己発光の両方へ同じように作用する。

LEDはPBRのEmissiveで自己発光する。乳白カバー／側面・前面の光源は強度5、表示LEDは4。HDR環境の照明強度をゼロにしても発光が残る。実際の照度を校正した値ではなく完成イメージ用の相対強度。

Selective BloomはEmissive材質を持つメッシュだけを対象にし、白いケースやボタンのHDR反射へは適用しない。LEDのOFFでEmissiveをゼロにし、Bloomも停止する。露出スライダーとは独立した発光ON／OFFとなる。

回帰テストでは最終描画の不透明ピクセルの輝度を読み、−1 EVで暗くなること、IBL強度ゼロでもLEDのONがOFFより明るいことをPC・モバイルで検証する。

## RGBと操作モード

RGBは「流れるレインボー」「ブリージング」「操作に反応」「単色 / アニメーション停止」から選択し、色・速度を調整できる。発光帯は1次元のRGB Emissiveテクスチャ、方向・ボタン表示灯は独立したEmissive材質でアニメーションする。操作時には対応する表示灯が強く光る。単色モードは自動の色変化を停止する。画面外・非表示タブでは更新を止め、動くRGBは最大約30回/秒で更新する。

「操作する」で操作モードへ切り替えると、組立状態へ戻り、自動回転を停止してカメラ操作から部品操作へ切り替わる。

- レバー：球をドラッグ、WASD / 矢印キー、画面内の方向ボタン。
- 6ボタン：3D上のキャップを押す、U I O / J K L、画面内の対応ボタン。
- 補助ボタン：1キーで1P、EnterでSTART。
- タッチ、複数キーの同時押し、ポインターキャンセル、フォーカスを失ったときの入力解除に対応。

動きはバネ・減衰の簡易物理モデル。最大1/240秒のサブステップで積分し、ボタンは約1.8 mm押し込み、レバーは最大約18°で可動域を制限する。離すと反発・減衰を伴って戻る。レバーは取り付け面の位置を支点としてシャフトと球を回転させ、キャップだけが押し込まれる。動作はWeb上のメッシュへ適用する。

背景はプリセットとカラーピッカーで選び、グリッドも切り替えられる。背景色を選ぶとHDR背景をOFFにする。暗い背景では補助文字のコントラストも変更する。

SSAOは強さ0〜4、範囲1〜20%（画面解像度に対するサンプリング半径）で調整可能。既定は強さ1.2・範囲5%。全体リセットで既定へ戻る。

### Tab5 の操作画面

操作モードでは Tab5 の画面でレバーとボタンの入力状態を確認し、U ボタンの連射と U→I→O／J→K→L のマクロを試せます。チルトに合わせて GPIO フラットケーブルの余長部も動きます。
